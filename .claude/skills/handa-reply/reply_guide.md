# 繁田の返信の型（reply_guide.md）

根拠は繁田本人が書いた返信2通（`examples.md`）。2026-10-14。

## 0. 一言で

**短く、軽く、礼を言って、相手の選択や報告を肯定して、ドアを開けておく。** 持論も体験談も語らない。

## 1. 構成

**核（ほとんどの返信に入れる）は 4〜7。** 1〜3、8〜10 は相手との関係で変える。

| # | 要素 | 例 | 可変／核 |
|---|---|---|---|
| 1 | 宛名 | 「◯◯さま」（ひらがなの「さま」） | 可変 |
| 2 | 名乗り | 初対面に近い相手:「こんにちは、TESTEAの繁田です。」／長く読んでいる相手:「お久しぶりです！繁田です。」。「塾長」は付けない | 可変 |
| 3 | 礼 | 1つか2つ。連絡への礼、相手がしてくれたことへの礼（体験に来た、いつも読んでくれている）。各1文 | 可変 |
| 4 | **本音・感想を1行** | 「嬉しい反面、少し残念でもあります（笑）」「認知症も睡眠も、結局は日々の生活習慣が大切ということですよね（笑）」。隠さないが1行で終える。（笑）は付けても付けなくてもよい | **核** |
| 5 | **相手の選択・報告を短く肯定** | 「中2の男の子が友達のいる環境で頑張りたいと思うのは自然なことですし、それが勉強のモチベーションにつながるなら何よりです」「こうして活躍のご報告をいただけるのは本当に嬉しいです」。持論や体験談で裏付けない | **核** |
| 6 | **励まし・お祝い1文＋「！」** | 「まずはそちらで楽しく、しっかり勉強が進むといいですね！」「全国大会出場おめでとうございます！！」（大きなお祝いは「！！」） | **核** |
| 7 | **締め** | 「また先々、◯◯で気になることが出てきたら、いつでも遠慮なくご相談ください。」＋「引き続き／今後ともよろしくお願いします！」 | **核** |
| 8 | 断り・返事が要る用件 | 理由を添えて一文。「11月8日はあいにく終日先約があり、伺うことが叶いません。」謝罪を重ねない。**直後に相手の子へのエールを一文**（「◯◯くんにぜひ頑張ってとエールをお伝えいただければ幸いです」） | 用件があれば |
| 9 | 追伸 | 相手に追伸があれば、追伸で軽く返す。自虐の一言＋（笑）。「私の強い味方はホッピー（外のみ）です（笑）」。P.S. は署名の前 | 任意 |
| 10 | 署名 | 「繁田」だけ | 固定 |

## 2. 数字と癖

- 長さ **150〜300字**。段落は1〜2文。段落の間に空行
- 「！」は励まし・お祝い・締めに。大きなお祝いは「！！」
- （笑）は1通に0〜2回。相手による
- 「ですし」「何よりです」「いいですね」の柔らかい接続。「〜させていただく」の多用なし
- 子どもは名前で呼んでよい（「◯◯くん」「◯◯さん」）。学年＋性別（「中2の男の子」）でもよい
- **相手のメールの話題を全部拾わない。** 本文で返すのは1〜2つ。季節のご自愛・相談の細部は返さなくてよい。2つにまとめられるなら1行にまとめる

## 3. 語彙

- 「TESTEA」（返信の名乗りは英字）。メルマガ本文の「テスティー」とは違う
- 「子ども」（子供は使わない）
- 「我々」「私たち」は返信ではほぼ使わない（「私」）

## 4. やらない（没になったAI案の特徴。1つでも該当したら削る）

| やらない | 理由（本人の言葉） |
|---|---|
| 持論を展開する（「塾が続くかどうかを一番左右するのは…」） | 「重すぎます」「全然僕が書くメールの文章じゃない」 |
| 自分の体験談を足す（「私自身も中高はサッカー部で…」） | 同上。返信に本人の出来事は要らない |
| 相手の文を一文ずつなぞって感想を返す（「〜とのこと。すごく自然だなと思いました」） | 「あまりにもAIっぽい」 |
| 相手の話題を全部拾う（睡眠の助言、ご自愛の返し、細部への言及） | 本人は6話題のうち本文で2つだけ返した |
| 「クスッとしてしまいました（笑）」の演技的な笑い | AIっぽい |
| 「〜でありますように」の詩的な締め | AIっぽい。本人は「よろしくお願いします！」で切る |
| 「よく見てきました」型の根拠の無い経験談、「教室からも聞いていました」の未確認事実 | 捏造 |
| 事務的な続き（「夏にお話しした内容は久我山校に残っています」） | ドアを開けるのは「いつでもご相談ください」だけ |
| 「予定を確認してみますね」の保留 | 本人が決めること。行く／行けないを聞いて書く |
| 「それはそれで悪くない」の二重のぼかし | 言い切るか、言わないか |

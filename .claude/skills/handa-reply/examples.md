# 見本（examples.md）

名前はすべて伏せてある。本人の見本は原文のまま（固有名詞だけ置換）。

## 見本1（採用・本人執筆）: 体験に来たが別の塾を選んだ家庭への返事

相手のメール（要旨）: 夏に久我山校で体験。感触は良く入塾するつもりだったが、子が2学期に転部し、部活帰りに友達のいる塾に通いたいと言い出した。「動機が不純で続くか怪しい。その際はまたお世話になります」

```
◯◯さま

こんにちは、TESTEAの繁田です。
ご丁寧にご連絡いただきありがとうございます。
また、夏は久我山校にお越しいただきありがとうございました。

体験の感触が良かったと伺い、嬉しい反面、少し残念でもあります（笑）

ただ、中2の男の子が友達のいる環境で頑張りたいと思うのは自然なことですし、それが勉強のモチベーションにつながるなら何よりです。

まずはそちらで楽しく、しっかり勉強が進むといいですね！

また先々、成績面や勉強への取り組み方などで気になることが出てきたら、いつでも遠慮なくご相談ください。

引き続きよろしくお願いします！

繁田
```
約250字。礼2つ→本音1行（笑）→一般論で肯定→励まし！→ドア→締め！→署名。

## 見本2（採用・本人執筆）: 長く読んでいる保護者からの近況と招待への返事

相手のメール（要旨）: メルマガ（認知症と睡眠の話）に同感、生活習慣を変え始めた／高2の子の寝る時間が遅いのが気になる／11月8日に子が管弦楽コンテストの全国大会で東京へ。見に来てほしい／季節の変わり目ご自愛を／追伸: 会食ではノンアルコールビールで過ごしている

```
◯◯さま

お久しぶりです！繁田です。
いつもメルマガをお読みいただきありがとうございます。

認知症も睡眠も、結局は日々の生活習慣が大切ということですよね（笑）

そして△△くん、全国大会出場おめでとうございます！！
もう高2というのも驚きですが、こうして活躍のご報告をいただけるのは本当に嬉しいです。

11月8日はあいにく終日先約があり、伺うことが叶いません。
△△くんにぜひ頑張ってとエールをお伝えいただければ幸いです。

今後ともよろしくお願いします！

P.S.
私の強い味方はホッピー（外のみ）です（笑）

繁田
```
約230字。6つの話題のうち本文で返したのは2つ（生活習慣を1行にまとめ、全国大会のお祝い）。睡眠の助言とご自愛の返しは無し。招待は理由を添えて一文で断り、直後に子へのエール。追伸には追伸で自虐。

## 没1（AI案・部下の方作）: 見本1と同じ相手への案

```
◯◯様

ご丁寧なお返事、ありがとうございます。
テスティーの繁田です。

夏の体験のときのお話、教室からも聞いていました。
手応えを感じてもらえていたようで、それだけでも嬉しいです。

部活帰りに、仲の良いお友達と一緒に通える場所を選ばれたとのこと。理由としては、すごく自然だなと思いました。
きっかけが勉強そのものじゃなくても、「一緒に行きたい」と思える場所があるのは、それはそれで悪くないと思っています。

動機が不純かもしれない、というくだり、正直クスッとしてしまいました（笑）。
でも、不純なきっかけから始まって、気づけば本人のペースになっていた、という話は実はよく見てきました。
続くかどうかは、あまり気にされなくて大丈夫だと思います。

また「ちょっと違うな」と感じるタイミングがあれば、そのときは遠慮なく声をかけてください。
いつでも歓迎します。

△△さんの学校生活が、楽しいものでありますように。

個別指導塾テスティー
塾長　繁田和貴
```
本人の評価: 「あまりにもAIっぽい」。相手の文を一文ずつなぞる／「教室からも聞いていました」の未確認事実／「クスッと」の演技／「よく見てきました」の根拠なし／「それはそれで悪くない」の二重のぼかし／「〜でありますように」の詩的な締め／署名が重い。

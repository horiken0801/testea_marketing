# 日吉校 募集案内文 更新（募集停止 → 募集再開）

## 背景

日吉校教室長より、ホームページに掲載している募集停止の案内文を以下の内容に書き換える依頼があった。

- センター南校の開校に伴い、日吉校の募集を再開する
- 空き枠についてはお問い合わせいただく形にする

※ このテキストは日吉校のWordPressページ（`https://testea.net/school/hiyoshi/`）に直接掲載されているもので、このリポジトリにはテンプレートファイルが存在しない（本リポジトリはキャンペーン企画・運用ドキュメントの管理用で、日吉校のWP themeファイルは別管理）。そのため、以下のHTMLを**WordPress側の該当ブロック（固定ページ/テンプレートのHTML編集画面）に直接貼り替える**対応が必要。

## 変更点

- 見出しを「生徒募集停止について」→「生徒募集再開について」に変更
- 「当面の間、募集停止」の文言を削除し、「センター南校の開校に伴い、募集を再開する」旨に変更
- 「募集再開は改めて案内」の文言を削除し、「空き枠についてはお問い合わせください」の案内に変更
- 結びの文言を、お詫び・ご理解のお願いから、お申し込みをお待ちする旨の案内に変更

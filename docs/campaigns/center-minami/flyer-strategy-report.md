# 個別指導塾TESTEA センター南校 開校チラシポスティング戦略メモ

- 運営: 個別指導塾TESTEA
- 対象校: センター南校（〒224-0032 横浜市都筑区茅ケ崎中央44-14 SHOKENセンター南ビル202）
- 開校予定: 2026年10月26日
- 既存実績: 日吉校（約10年運営・全時間帯満席の人気教室）
- 協力会社: 株式会社アト（商圏分析データ「TerraReport Plus」提供）
- 作成: 堀内
- プレゼン資料（Artifact版）: https://claude.ai/artifact/WDYRkYLHFMj1RCKeLBdgo8

## 結論

アトさんの商圏データは、この立地の強み（高所得・子育てファミリー集中・将来も人口が減らない）を裏付ける良質な材料。加えてTESTEAは日吉校を約10年運営し、全時間帯満席という実証済みの支持を得ているブランドであり、センター南校は「未知の新規参入」ではなく「実績あるブランドの新規出店」として訴求できる。ただし以下は上長への説明前に埋めておくべき懸念。

1. エリア単位の過去配布実績データがなく、部数設定が経験則ベース（アトさんのメール上でも明言済み。ただしTESTEA自体は日吉校で10年分の集客実績を持つ）
2. 駅前0.5km圏は実は単身・賃貸層が中心で、ファミリー訴求とややズレる
3. 個別指導塾の競合（スクールIE、スタディコーチ、個別指導WAM、森塾、臨海セレクト、理数個別指導学院、湘南ゼミナール個別指導コース等）が周辺に7ブランド前後集積
4. 開校日（10/26）からの逆算スケジュールがタイトで、意思決定を急ぐ必要がある
5. 反響を測定する仕組み（クーポン番号等）が未設計

## ② 独自リサーチ（センター南駅・都筑区）

- センター南駅は横浜市営地下鉄ブルーライン・グリーンラインの結節駅で、港北ニュータウンの中核駅。駅前は港北東急SC等の商業集積があり、歩行者専用遊歩道でつながる計画都市。
- 大東建託「いい部屋ネット 子育て世帯の街の住みここちランキング2025（首都圏版）」で都筑区は自治体部門**首都圏第2位**。
- 都筑区は令和4年4月時点で**待機児童ゼロ**。認可保育所等68施設、認定こども園・幼稚園15施設。
- 横浜市「令和元年度市民意識調査」で暮らしやすさ満足度18区中**都筑区が1位（60.7%）**。犯罪率も県平均より低い。
- 教室周辺（茅ケ崎中央・茅ケ崎南1〜5丁目・中川6丁目・中川中央1丁目・長坂・荏田東4丁目等）は5〜14歳人口の実数が多い。周辺の茅ケ崎小学校（児童813人）・茅ケ崎東小学校（801人）・茅ケ崎中学校（897人）も在籍数が多め。
- 競合：TESTEAと同じ個別指導形式だけでも、スクールIE（英数個別・国理社小集団）、スタディコーチ（東大生伴走型個別指導）、個別指導WAM、森塾（先生1人に生徒2人までの個別指導）、臨海セレクト、理数個別指導学院（完全1対1）、湘南ゼミナール個別指導コースなど駅周辺だけで7ブランド前後が確認でき、集団指導中心の湘南ゼミナール本科・臨海セミナーも含めると極めて激しい競争環境。
- 業界相場：教育系ポスティングの反響率は0.2〜0.5%、教室商圏の目安は徒歩・自転車1.5〜2km（送迎ありなら3〜5km）。アトさんの1.5km圏設計は業界標準と整合。

## ③ 統合判断

### 判断基準

1. ターゲット適合度（年齢層・所得層・世帯タイプ）
2. 配布ボリュームと費用対効果
3. 競合状況と差別化余地
4. スケジュール成立性（開校日からの逆算）
5. 効果検証の仕組み

### 良い点

- 1.5km圏という商圏設計は業界標準と一致し妥当
- 年収・生活者クラスタの両面で「教育サービスに合う富裕ファミリー層」が定量的に裏付けられている
- 将来人口が2050年まで増加し続ける稀有な立地
- 教室至近に子どもの絶対数が多いエリアが集中しており、重点配布先を具体的に特定できる
- TESTEAは日吉校で約10年・全時間帯満席の実績があり、「実績未知の新規参入」ではなく「支持されてきたブランドの新規出店」として訴求できる

### 懸念事項

- エリア単位の過去配布実績データがなく、部数設定がアトさんの経験則ベース（日吉校の内部データで補強できないか要確認）
- 駅前0.5kmは単身・賃貸中心でファミリー訴求とややミスマッチ（部数を「駅に近い順」に厚くすると非効率）
- 個別指導塾の競合が7ブランド前後あり、差別化訴求なしでは埋没するリスク
- スケジュールがタイトで、9月中の意思決定が必要
- 反響測定の仕組みが未設計

## 堀内案（仮説）

1. 商圏は1.5km円を維持しつつ、部数は1〜1.5km圏の住宅密集エリア（茅ケ崎南1〜5丁目・中川6丁目・中川中央1丁目・長坂・荏田東4丁目等）に傾斜配分
2. 配布は3回（開校前・開校直後・開校1か月後）、初回の意思決定を最優先で今月中に
3. チラシの主訴求を「日吉校10年・全時間帯満席」の実績訴求＋開校記念特典の二本立てにする。個別指導塾が7ブランド前後ひしめく中、単なる開校告知では埋没するため、先に「選ばれてきたブランド」という信頼を伝え、そのうえで初月無料等の特典で今動く理由を添える
4. クーポン番号や来校時アンケートで反響を測定し、2・3回目の配布計画にフィードバック
5. 日吉校がどのチャネル（口コミ・紹介・ポスティング・Web等）で生徒を獲得してきたかを教室責任者・本部に確認し、アトさんの業界類推値を補強する社内データとして活用する

- 個別指導塾の競合が7ブランド前後あり差別化が必要なこと

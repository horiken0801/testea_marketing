## 受験体験記 掲載に関する確認書

TESTEA個別指導塾 [校舎名]校

生徒様氏名：＿＿＿＿＿＿＿＿＿＿＿＿　　ご記入日：　　年　　月　　日

このたびの受験体験記について、下記のとおり掲載可否を確認させていただきます。
ご希望の項目に☑（チェック）をご記入ください。

### 1. 掲載媒体（複数選択可）

- [ ] 塾のホームページ・ブログ
- [ ] チラシ・パンフレット等の紙媒体
- [ ] SNS（X / Instagram / Threads 等）
- [ ] Googleビジネスプロフィール（GBP）掲載・紹介
- [ ] 上記いずれも不可（体験記は社内資料としてのみ使用）

### 2. お写真の掲載

- [ ] 顔写真の掲載を許可する
- [ ] 後ろ姿・手元など、顔が分からない写真のみ許可する
- [ ] 写真掲載は不可

### 3. 進学先（学校名）の掲載

- [ ] 学校名をそのまま掲載してよい（例：「〇〇中学校」）
- [ ] 学校種・地域のみ掲載してよい（例：「都内私立中学校」「公立中高一貫校」）
- [ ] 学校名・学校種とも非公開としてほしい

### 4. お名前の表記方法

TESTEAでは、過去の運用上**イニシャル表記を基本**としています。本名掲載をご希望の場合のみ
「本名可」にチェックしてください。

- [ ] 本名のイニシャルのみで掲載してよい（例：「K.H.さん」）※基本の表記方法
- [ ] 本名（フルネーム）で掲載してよい
- [ ] ニックネーム・匿名（「生徒様」等）での掲載を希望する

### 5. 掲載期間・同意の撤回について

- 掲載期間：ご提出いただいた同意の範囲で、**期間を定めず使用**させていただきます。
  掲載の中止・修正をご希望の場合は、いつでも教室または本部マーケティング部までご連絡ください。
  ご連絡をいただき次第、速やかに対応いたします。
- 本確認書・体験記原稿は、本部マーケティング部にて管理し、目的（上記掲載媒体での使用）以外には
  使用いたしません。

### 6. ご本人確認（フォーム上の入力項目）

生徒様氏名（フォーム入力）

保護者様氏名・ご連絡先（フォーム入力・必須／署名の代替）

### 校舎スタッフ向けメモ

- 保護者様氏名・ご連絡先の入力を必須とすること（未成年のため、署名の代替として機能させる）。

# 2027受験体験記・GBP口コミ依頼 対応パッケージ

田町校 教室長より依頼のあった「受験体験記（GBP掲載含む）」の作成に伴い、
生徒様・保護者様へお渡しする依頼文・同意書・回収ルールをまとめたパッケージです。
対面回収を基本としつつ、対面機会が取れない場合はオンライン（Googleフォーム）での回収にも対応しています。

## オンライン回収用フォーム

- 受験体験記フォーム：<https://forms.gle/fzcXfeikhcYL4x9h7>
- 掲載可否確認書フォーム：<https://forms.gle/92rKt71QVQngLoS18>

いずれも `consent-form.md` と同じ質問項目構成で作成済みです（2026-10作成）。

## 背景

- 推薦合格によりご卒塾予定のお客様から、受験体験記・GBP（Googleビジネスプロフィール）口コミへの
  ご協力をお願いする場面を想定（田町校：2026-10時点で1件発生）
- 教室長より、依頼用定型文とレギュレーション（写真・学校名掲載可否、回収方法、留意事項）の共有依頼あり
- 依頼文は、Slack上に残る過去の実運用（2025年度の受験体験記依頼フロー、2026年9月の全校舎向け
  Googleクチコミ依頼文、繁田さん・松尾さん確認済み）を引用・踏襲して作成（各ファイル内に出典を記載）

## 構成

- `request-template.md` — 生徒様・保護者様へお渡しする依頼文（定型文）。受験体験記用・GBP口コミ用の2種
- `consent-form.md` — 掲載可否確認書（同意書）フォーマット。写真・学校名・氏名表記・掲載媒体・同意撤回について確認
- `collection-guidelines.md` — 回収方法（対面回収の進め方）、レギュレーション、法令・ポリシー上の留意事項

## 校舎での使い方

> **運用更新（2026-10）**：掲載可否確認書は紙の印刷・対面署名ではなく、
> **Googleフォームへの入力に統一**しました（対面で依頼する場合も、その場でスマホから入力いただく運用）。

### 対面で依頼する場合

1. `request-template.md` の依頼文を印刷し、生徒様・保護者様へお渡し・口頭でご説明
2. 掲載可否確認書フォーム（<https://forms.gle/92rKt71QVQngLoS18>）に、その場または後日ご自宅から
   入力いただく（保護者氏名・連絡先の入力が署名の代替）
3. 体験記原稿（手書き可・指定フォーマットなし）を対面回収
4. 教室長がフォーム回答・体験記原稿の記入漏れを確認し、本部（マーケティング部）へ提出
5. GBP口コミは依頼文に沿ってご本人・保護者様のGoogleアカウントから直接投稿いただく（塾側での代筆・投稿代行は行わない）

### 対面の機会が取れない場合

1. `request-template.md` の依頼文とともに、受験体験記フォーム・掲載可否確認書フォームの両方のリンクをご案内
2. 保護者様ご自身にフォームへ回答・入力いただく
3. 教室長・本部マーケティング部がフォーム回答（スプレッドシート）を確認、記入漏れがあれば個別に補完依頼
4. GBP口コミは依頼文に沿ってご本人・保護者様のGoogleアカウントから直接投稿いただく

不明点があれば、提出前にマーケティング部（堀内）まで確認してください。

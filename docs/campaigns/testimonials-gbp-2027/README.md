# 2027合格体験記・GBP口コミ依頼 対応パッケージ

田町校 教室長より依頼のあった「合格体験記（GBP掲載含む）」の作成に伴い、
生徒様・保護者様へお渡しする依頼文・同意書・回収ルールをまとめたパッケージです。
対面回収を想定した運用を前提にしています。

## 背景

- 推薦合格によりご卒塾予定のお客様から、合格体験記・GBP（Googleビジネスプロフィール）口コミへの
  ご協力をお願いする場面を想定（田町校：2026-10時点で1件発生）
- 教室長より、依頼用定型文とレギュレーション（写真・学校名掲載可否、回収方法、留意事項）の共有依頼あり

## 構成

- `request-template.md` — 生徒様・保護者様へお渡しする依頼文（定型文）。合格体験記用・GBP口コミ用の2種
- `consent-form.md` — 掲載可否確認書（同意書）フォーマット。写真・学校名・氏名表記・掲載媒体・同意撤回について確認
- `collection-guidelines.md` — 回収方法（対面回収の進め方）、レギュレーション、法令・ポリシー上の留意事項

## 校舎での使い方（対面回収フロー）

1. `request-template.md` の依頼文を印刷し、生徒様・保護者様へお渡し・口頭でご説明
2. `consent-form.md` の同意書に、掲載可否の希望（写真・学校名・氏名表記など）をご記入いただく
3. 体験記原稿（手書き可・指定フォーマットなし）と同意書をセットで対面回収
4. 回収後、教室長が記入漏れ・同意欄の確認を行い、本部（マーケティング部）へ提出
5. GBP口コミは依頼文に沿ってご本人・保護者様のGoogleアカウントから直接投稿いただく（塾側での代筆・投稿代行は行わない）

不明点があれば、提出前にマーケティング部（堀内）まで確認してください。

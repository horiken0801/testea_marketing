# 依頼用定型文（受験体験記・GBP口コミ）

校舎で印刷・配布する際は `[ ]` 内を校舎名・生徒様氏名等に置き換えてください。
いずれも**任意のご協力依頼**であり、強制や謝礼の提供を前提としないことを明記しています
（景品表示法のステマ規制・Googleの口コミポリシー対応のため。詳細は `collection-guidelines.md` 参照）。

> 以下の2本は、過去にSlack上（#021_久我山校・#026_田町校・#028_市ヶ谷校 等、2025-12-18／
> DM、#100_生徒集客全般 2026-09-02・09-10）で実際にマーケティング部から校舎・保護者様へ送付し、
> 繁田さん・松尾さんの確認も得て使用した文面をベースに、2027年向け・対面回収用に調整したものです。
> 一から新規作成したものではなく、既存の運用実績がある文面であることを前提にご利用ください。

## 1. 受験体験記ご依頼文（生徒様・保護者様向け）

件名：【ご相談】受験体験記作成へのご協力のお願い

[生徒様氏名]様・保護者様

こんにちは。個別指導塾TESTEA [校舎名]校の[教室長名]です。
いつも大変お世話になっております。

このたびは、改めまして[生徒様氏名]様のご卒塾・ご進学、誠におめでとうございます。

現在TESTEAでは、これから受験を迎える生徒様・保護者様に向けて、実際に合格を経験された
ご家庭の声をお届けすることを目的に、「受験体験記」の作成を進めております。
そこで大変恐れ入りますが、[生徒様氏名]様・保護者様に、受験体験記作成へのご協力を
ご検討いただけないかと思い、ご連絡いたしました。

**ご相談内容**

- TESTEAのホームページ等WEBサイトや広報誌などの広告媒体への掲載にご同意いただける範囲で、
  「塾を選んだ理由」「頑張ったこと」「後輩へのメッセージ」などを中心に、
  体験記をご記入いただけませんでしょうか（指定の書式はございません。目安400〜800字程度）。
- 文章を書くのが難しい場合は、対面で10〜15分ほどお話を伺う簡単な聞き取り形式でも構いません。
  その場合はスタッフが聞き取った内容を体験記の形にまとめ、公開前に必ずご確認いただきます。
- 掲載にあたり、お写真・学校名・お名前の表記方法については、下記の掲載可否確認書フォームに
  ご入力をお願いいたします（掲載可否はすべて選択制です。お名前は原則イニシャル表記を基本としていますが、
  本名掲載をご希望の場合はその旨お選びいただけます）。

- 掲載内容（写真・掲載範囲等）は、事前に必ずご確認・ご相談のうえで進めます。
- 「体験記のみ可、写真や学校名の掲載は不可」など、一部のみのご協力でも差し支えございません。

## 2. GBP（Googleビジネスプロフィール）口コミご依頼文（生徒様・保護者様向け）

件名：Google口コミ投稿のお願い

いつも個別指導塾TESTEA [校舎名]校をご利用いただき、誠にありがとうございます。

このたびは、[生徒様氏名]さんのご卒塾・ご進学、誠におめでとうございます。
[校舎名]校の講師一同、[生徒様氏名]さんの頑張る姿から日々多くの元気をもらっており、
大変嬉しく思っております。

このたび、もしよろしければ、教室や担当講師の様子について、Googleクチコミへの投稿に
ご協力いただけないでしょうか。今後、塾選びをされる他の保護者さまの参考になるとともに、
日々指導にあたる講師にとっても大きな励みになります。

- 所要時間は1〜2分程度です。
- 評価点数や文章の長さに決まりはありません。「テスティーを選んでよかったと感じた点」や
  「受験に向けてお子さまが頑張っていたこと」など、感じたことを率直にお書きいただけますと幸いです。
- お名前を出さずに投稿したい場合は、投稿前にGoogleマップのプロフィールでニックネームを
  設定いただくことで、本名を出さずに投稿いただくことも可能です（手順は下記のご案内をご参照ください）。
- 任意のお願いですので、ご都合が合わない場合は無理にご対応いただかなくて大丈夫です。
- 謝礼・特典等のご用意はございません。率直なご感想をお願いいたします。

▼Googleクチコミ投稿はこちらからお願いいたします。
[校舎名]校：[校舎別の口コミ投稿用リンクを挿入／リンク一覧は collection-guidelines.md 参照]

▼匿名（ニックネーム）の設定方法のご案内
ニックネームを設定してから投稿したい場合の手順は、以下をご覧ください。
1. Googleマップアプリを開く
2. 右上のプロフィール写真をタップ
3. 「あなたのプロフィール」または「プロフィール」へ進む
4. 「プロフィールを編集」をタップ
5. 「投稿にカスタムの表示名と写真を使用する」をオン
6. 表示名に、公開したいニックネームを入力
7. 必要なら写真も変更
8. 保存して完了
こちらを完了後、上記リンクを押していただけますと匿名（ニックネーム）での投稿が可能となります。

今後とも[生徒様氏名]さんの新しい環境でのご活躍を応援しております。

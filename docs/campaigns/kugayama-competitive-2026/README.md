- 夏季のオファー構成（実績あり・再現性高いと判断）:
  1. 入会金22,000円 → 無料
  2. 塾長執筆の中学受験合格ノウハウ本プレゼント
  3. 体験授業無料
  4. 友だち紹介でAmazonギフト5,000円分

## 提案内容

1. 久我山校を秋キャンペーンの対象校舎として確定してもらう
2. 全社版の完成を待たず、久我山校だけ夏キャンペーンと同じオファー構成で先行スタート
3. ターゲットを小学生（中学受験）に絞り、早稲アカ個別の主戦場と正面から対抗
4. 未決・元在リストへの久我山限定アプローチを通常予定より前倒しで実施

# 商標保護・広告キーワード除外依頼リスト

他塾の検索広告（リスティング広告）で、自社の商標・屋号に関連する語句が無断で使われないよう、Google広告・Yahoo!広告へ除外依頼を行う際のキーワード案。

前提: 正式名称は「テスティー」「Testee」「testea」を商標登録・使用。単一拠点・オンライン中心のため地域名との掛け合わせは含めず、オンライン系ワードを厚めにしている。

## 依頼書作成時の実務ポイント

- Google広告・Yahoo!広告それぞれ別書式・別窓口（Googleは商標オーナーによる「商標に関する苦情」フォーム経由、Yahoo!は広告ポリシー窓口）のため、依頼は媒体ごとに出す必要がある。
- 除外依頼の対象は基本的に「広告文・表示URL」への無断使用で、競合が自社の商標を**入札キーワードとして使うこと自体**は媒体ポリシー上制限しにくいケースが多く、効果が出やすいのは「広告見出し・説明文にブランド名を表示している」ケース。狙いをどちらに置くか整理しておくと依頼文が書きやすい。
- 自社の商標登録番号（あれば）を添付すると審査が早く進む。

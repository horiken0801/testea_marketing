# 学習塾のWEBマーケティング戦略（Cyvate社 提供資料 要約）

- 提供元: Cyvate株式会社（担当: 松本慎太郎氏 / s.matsumoto@cyvate.co.jp）
- 資料日付: 2026.10.05
- 位置づけ: テスティー向けに提供された、学習塾業界向けWEBマーケティングの一般的な戦略フレームワーク資料（全28ページ）。個別施策というより、広告運用の前提となる考え方・年間計画・チャネル別の型・KPI・法規制をまとめたリファレンス。

## 1. 基本の考え方

学習塾の集客には3つの特徴がある。
- **意思決定者が二重構造**: お金を払うのは保護者（主に30〜40代の母親）、「行きたい／行きたくない」を決めるのは生徒本人。広告は保護者へ、SNS発信や体験授業の満足度は生徒へ、と役割を分けて設計する。
- **季節講習は「入口商品」**: 春期・夏期・冬期講習は低価格・無料の入口として設定し、講習期間中に信頼関係をつくって本入塾へ移行してもらうのが基本の流れ。
- **商圏が狭い**: 生徒の大半は自転車や徒歩で通える半径2〜5km圏内から来る。地域名検索・Googleマップ・地域の学校情報などローカル施策が効く。

### 集客ファネルと毎月のKPI
認知 → 問い合わせ・資料請求 → 体験授業・面談 → 季節講習 → 本入塾 → 継続・紹介、という一本の導線で設計し、毎月以下4指標を追う。
- 問い合わせ数／体験授業の数／入塾率／退塾率

## 2. 年間計画と予算

- 広告は講習が始まる直前ではなく、**開始の4〜6週間前から出す**のが原則。
- 年間予算は均等に割らず、**春・夏・冬の講習前に集中投下**する（鉄則）。
  - 配分目安: 春（2〜4月）35% / 夏（6〜7月）35% / 冬（11〜12月）15% / その他の月 15%
- モデルケース（中学生向け個別指導塾、1教室、在籍50→70名目標、月謝2.5万円、年間広告予算約200万円）では、年間問い合わせ目標は約95件。そのうち約8割を春・夏・冬の3つの山で集める。
- 月別予算配分例: Google・Meta・チラシを合わせて年間202万円（Google 112万／Meta 35万／チラシ 55万）。8月はほぼ広告を止め、講習生の満足度向上と本入塾への移行に人手を割く。

## 3. チャネル別の施策（8チャネル）

| チャネル | 主な役割 | 向ける相手 | 力を入れる時期 |
| --- | --- | --- | --- |
| Googleビジネスプロフィール（MEO） | 地図検索からの問い合わせ獲得。費用ゼロで最も費用対効果が高い（**最優先**） | 保護者 | 最優先・通年 |
| Google検索広告 | 検討意欲が最も高い層を地域名キーワードで獲得 | 保護者 | 季節の山で集中 |
| Meta広告（Instagram・Facebook） | まだ塾を探していない潜在層の保護者に知ってもらう | 保護者 | 季節の山で集中 |
| LINE公式アカウント | 問い合わせの受け皿と育成、在籍生の保護者との連絡 | 保護者 | 通年 |
| SEO・ブログ | 地域特化情報で、広告費をかけない集客資産をつくる | 保護者 | 通年（約1年で効果） |
| Instagram・TikTok・YouTube | 生徒には「楽しそう」、保護者には「ちゃんとした先生」を伝える | 生徒・保護者 | 通年 |
| チラシ（ポスティング・折込） | 講習前の地域認知。QRコードでWEBに誘導し計測する | 保護者 | 講習前 |
| 紹介制度 | 最もコストが低く、入塾率・継続率ともに高い | 在籍生の家庭 | 講習前に案内 |

### Google検索広告
- キャンペーンを目的ごとに3分割: 季節講習60% / 地域×塾30% / テスト・受験10%
- 除外キーワード: 求人・アルバイト関連、家庭教師・通信教育・オンライン、大学受験・浪人、無料教材探し
- 配信地域は教室から半径3km（生活圏が川・線路で分かれる場合は町名単位で指定）
- 入札は最初の2週間「クリック数の最大化」→データが貯まったら「コンバージョン数の最大化」へ

### Meta広告
- Metaは18歳未満へのターゲティングを厳しく制限しているため、**生徒本人ではなく教室周辺の保護者**がターゲットの基本。
- ターゲット例: 教室から半径3kmに住む35〜54歳の保護者
- 予算例: 夏期2ヶ月で10万円（日予算 約1,700円）
- クリエイティブは3パターンを同時配信し、2週間ごとに反応の悪いものを差し替える
  - A. 実績型（点数アップの具体事例）／B. 雰囲気型（教室・自習室の様子）／C. 危機感型（「中3の夏、何をすればいい？」という問いかけ）

### 広告文
- 「時期×地域」で具体的に（例: 「夏期講習 受付中」「〇〇中 定期テスト対策」）
- 見出し全角15文字以内／説明文全角45文字以内
- 入れる3要素: 時期（受付中・早割締切・残席）、地域（駅名・中学校名・高校名）、行動のきっかけ（無料体験・LINEで予約・学習相談）

## 4. 夏期講習キャンペーン（週次プレイブック）

- 週次スケジュール例: 5月第4週（LP・チラシ制作）→6月（広告開始・体験受付）→7月第1〜3週（早割締切7/10、申込締切7/20がピーク）→7月第4週〜8月（広告縮小、本入塾への移行に注力）→9月第1週（2学期から塾を探す層へ再開）
- LP構成（上から順）: ファーストビュー→悩みの提示→解決策→実績→講師紹介→料金・日程→保護者の声→よくある質問→予約ボタン。予約ボタンは3回以上＋スマホでは画面下部に固定。料金は明示する。
- 講習生を本入塾につなげる5つの接点: 初回授業当日の連絡→講習中盤の学習報告→講習最終週の保護者面談→面談での9月入塾特典提示→8月31日の締切フォロー。「入塾しませんか」ではなく**具体的な計画を見せる**。
- 成果シミュレーション例: 問い合わせ合計約70件→講習申込み約47名（申込率67%）→本入塾約24名（入塾率50%）。CPA（入塾1人あたり）約2.7万円、LTV（1人あたり）約45万円＝獲得費用はLTVの約6%。

## 5. KPIと法規制

### 毎月追う6つの指標
問い合わせ数／体験授業の実施数／体験→入塾の転換率／講習生→本入塾の転換率／入塾単価（広告費÷入塾者数）／退塾率。広告は「問い合わせ単価」ではなく「**入塾単価**」で評価する。

### 気をつけるべき法規制・規約
- **景品表示法**: 「合格率〇%」「地域No.1」等の表記には根拠が必要。講習だけ受けた生徒を合格実績に含める場合はその旨を明記。
- **ステマ規制（2023年10月〜）**: 在籍生・保護者に謝礼を渡して口コミ・SNS投稿してもらう場合は、広告であることを明示する必要がある。
- **Googleの口コミポリシー**: 謝礼と引き換えの口コミ依頼や高評価だけのお願いは規約違反。依頼は満足度が高いタイミングで、率直な感想として行う。
- **Metaの年齢ターゲティング制限**: 18歳未満のユーザーへの広告ターゲティングは厳しく制限。広告は保護者に向けて設計する。
- **生徒の写真・実例の掲載**: 必ず本人と保護者の同意を取る。
- **「残席わずか」などの表現**: 実際の状況に基づいて行う。事実と異なる表現は避ける。

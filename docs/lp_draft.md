# 「中学受験準備応援キャンペーン」LP構成案(ドラフト・9/29決定反映版)

> 9/29マーケ部mtgの決定事項に基づき更新。9/10提案書時点の内容(3ヶ月間授業料免除・校舎選択制)は上書きされています。中村さん・半田さんとも「LPはAIで作ればいい」「既存の夏キャンLPを流用して書き換えるのが速い」と明言済みのため、実際に共有いただいた夏キャンLP(`https://testea.net/summer-campaign-2026/`)のHTMLをベースに、秋キャン内容へ書き換えたHTMLを作成しました。

**実際のHTMLファイル: `docs/lp_autumn_campaign/index.html`**(このドキュメントは構成メモとして残します)

入会金は22,000円で確定(公式サイト・夏キャンLPと一致)。以下は完成HTMLに反映済みの内容です。

## 前提(9/29時点の確定事項)
- 対象: 小学3・4・5年生(6年生は対象外)
- 内容: 週1コースを**2ヶ月間・最大8コマ無料**(振替なし、欠席したらその回は消化)
- 条件: 入会金のみ必須(**2.2万円/未変更の前提**で記載。変更があれば要修正)
- 実施期間: **2026年10月1日〜2ヶ月間**
- 告知トーン: 校舎選択制ではなく、本部決定事項としての告知(LP自体は保護者向けなのでこの点はLP上には出さない)

## ファーストビュー
- **メインコピー案**
  1. 「サピックスの入室テストは、もう始まっている。」
  2. 「小3・4・5年生のいま、始めるから間に合う。中学受験準備応援キャンペーン」
  3. 「週1回・最大8コマ無料。中学受験の"最初の一歩"を、テスティーで。」
- サブコピー: 「入会金のみで、8コマ分の授業料が0円。」
- 対象バッジ: 「対象:小学3・4・5年生」
- 期間バッジ: 「2026年10月1日スタート、2ヶ月間限定」

## 訴求構成(セクション順)
1. **課題提起**: 「大手進学塾の入室テストは小4開始が主流。小6での入会率はわずか2〜3%」という事実を提示し、早期スタートの重要性を伝える
2. **キャンペーン概要(表)**
   | 項目 | 内容 |
   |---|---|
   | 対象 | 小学3・4・5年生 |
   | 授業 | 週1コース |
   | 無料内容 | 最大8コマ無料(振替なし) |
   | 期間 | 2026年10月1日〜2ヶ月間 |
   | 料金 | 入会金のみ(2.2万円/要最終確認) |
3. **テスティーが選ばれる理由**: 定着率の高さ、面倒見の良い自主室、講師との関係性(既存の強み訴求ポイントを差し込む)
4. **申込みCTA**: 「無料相談・お申し込みはこちら」ボタン(複数箇所に配置)
5. **FAQ**: 「途中でやめられますか?」「振替はできますか?(→振替なしの仕様を明記)」「小6でも申し込めますか?(→対象外である旨を明記)」
6. **実施期間の明記**: 「本キャンペーンは2026年10月1日から2ヶ月間限定です」→検討期間に入らせない設計を明示

## デザイン・トーンの方針
- 「無料」を前面に出しすぎず、「準備を始めるなら今」という時間的切迫感を訴求の軸にする
- 低学年の保護者向けなので、安心感・柔らかい印象のビジュアルを想定

## `docs/lp_autumn_campaign/index.html` 作成時の対応・注意事項
- 入会金**22,000円で確定**として反映(ユーザー確認済み)
- 校舎の「残席わずか」等の**在庫・締切系の煽り表現は、実データがないため全て削除**しました(夏キャンLPでは校舎ごとに具体的な残席数が入っていましたが、秋キャンでは架空の数字を作らずフラットな校舎一覧のみにしています)。実際の校舎別の受付状況が分かれば、その情報をもとに追記できます
- 画像パス(`images/testea-logo-new.png` 等)は夏キャンLPと同じ相対パスのまま残しています。実際に配置する際は本番の画像ファイルへの参照に置き換えが必要です
- SATORIフォームの`data-key`は夏キャンLPのものをそのまま使っています。**秋キャン用のクリエイティブキーの発行・差し替えが必要**です(要確認)
- センター南校(11/1開校予定)は本キャンLP公開時点ではまだ未開校のため、校舎一覧には含めていません。開校後に追記してください
- FAQ・オファー訴求は「週1コース8コマ無料、入会金22,000円は通常通り」という9/29決定の内容で統一しています

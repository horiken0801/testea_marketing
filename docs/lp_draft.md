# 「中学受験準備応援キャンペーン」LP構成案(ドラフト)

> 9/10提案書・8/27議事録の決定事項に基づくドラフトです。校舎数・具体的な校舎名・キャンペーン適用条件の最終確認後に確定させてください。

## ファーストビュー
- **メインコピー案**
  1. 「サピックスの入室テストは、もう始まっている。」
  2. 「小3・4のいま、始めるから間に合う。中学受験準備応援キャンペーン」
  3. 「週1回・45分から。中学受験の"最初の一歩"を、テスティーで。」
- サブコピー: 「入会金2.2万円のみ。授業料は3ヶ月間0円。」
- 対象バッジ: 「対象:小学3・4年生(校舎により小1・2年生も可)」

## 訴求構成(セクション順)
1. **課題提起**: 「大手進学塾の入室テストは小4開始が主流。小6での入会率はわずか2〜3%」という事実を提示し、早期スタートの重要性を伝える
2. **キャンペーン概要(表)**
   | 項目 | 内容 |
   |---|---|
   | 対象 | 小学3・4・5年生 |
   | 授業 | 週1回・45分 |
   | 期間 | 入会から3ヶ月間 |
   | 料金 | 入会金2.2万円のみ・授業料完全免除 |
   | 振替 | 欠席時の振替なし(気軽に始められる分、無理のない設計) |
3. **テスティーが選ばれる理由**: 定着率の高さ、面倒見の良い自主室、講師との relationship(既存の強み訴求ポイントを差し込む)
4. **対象校舎・定員の表示**: 「先着◯名」「残り◯名」形式(校舎ごとに動的に差し替え可能な設計にする)
5. **りんご塾体験イベントの案内(実施校舎のみ表示)**: 対象年齢・実施日・申込方法
6. **申込みCTA**: 「無料相談・お申し込みはこちら」ボタン(複数箇所に配置)
7. **FAQ**: 「途中でやめられますか?」「振替はできますか?」「小5・6でも申し込めますか?」等
8. **実施期間の明記**: 「本キャンペーンは2026年9月・10月限定です(反響により11月まで延長する場合があります)」→検討期間に入らせない設計を明示

## デザイン・トーンの方針
- 「無料」を前面に出しすぎず、「準備を始めるなら今」という時間的切迫感を訴求の軸にする(松尾さんの「9月に入った時点で一気にアクセルを踏む」方針に合わせる)
- 低学年の保護者向けなので、安心感・柔らかい印象のビジュアルを想定(色調・写真の方向性は追って調整)

- [ ] 定員数(校舎ごと)
- [ ] キャンペーン終了後の申込みフロー(通常料金への切り替え案内)

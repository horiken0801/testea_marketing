## ① 内容のまとめ

### 背景・目的
- 大手進学塾(サピックス等)の入室テストは小4開始が主流。小6での新規入会率は2〜3%程度と低く、**低学年(小3・4)での早期接点確保**が中長期的な在籍継続に直結するという中村さんの指摘が起点。
- 秋(9〜11月)は「中学受験をするかどうか」を検討し始める家庭が多いタイミング。
- 単年の件数目標よりも**「毎年同時期に再現できる型」を作ることを重視**(松尾さんの視点)。8月中旬に検討していた4イベント案(りんご塾合同イベント・缶詰道場・おためし入試・戦略診断DAY)は、この方針転換により本提案に一本化された。

### 決定している施策内容(9/10提案書ベース)
**対象**: 小学3・4年生を主対象(小6は対象外。校舎判断で小1・2を含めることも可)

**A. 中学受験準備応援キャンペーン(メイン・全校舎選択制)**
| 項目 | 内容 |
|---|---|
| 対象 | 小3・4・5年生 |
| 頻度/時間 | 週1回(校舎選択)・45分/回 |
| 期間 | 入会から3ヶ月間 |
| 料金 | 入会金2.2万円のみ、授業料は期間中完全免除 |
| 振替 | 欠席時の振替対応なし(権利消化のみ、運営負荷を最小化) |
| 実施期間 | 9・10月に集中実施、反響次第で11月まで延長可 |

**B. りんご塾 体験イベント(フロントエンド集客・実施校舎限定)**
- 研修済みスタッフ(津村さん・本間さん・菅原さんなど)が対応可能な3〜4校舎程度で実施
- 祝日または日曜午前中心(通常授業と非重複)
- 9/6プレファミ祭ブースの内容(パズル・積み木体験)を横展開、告知チラシも流用

**運用ルール**: 管理本部から「全校舎必須」で強制せず、A・Bを選択肢として提示し、**各校舎が自校の体制に応じて選ぶ方式**(校舎ごとに先着◯名等の定員設定可)。ホームページには実施を選んだ校舎のみ掲載。

## ② やることのスモールタスク化

大きく5つのフェーズに分解できる。

### フェーズ1: 企画確定・社内承認
1. 部長会議での最終承認取得(施策A・B、選択制の提示方法、想定費用/逸失収益試算の承認)
2. Aキャンペーンの逸失収益試算を校舎別に作成
3. 承認内容を反映した提案書の最終版化

### フェーズ2: 校舎への案内設計
4. 校舎向け案内文言・案内フォーマットの作成(「これを実施してください」ではなく「選ばせる」トーンで)
5. 校舎ごとの定員(先着◯名)設定ルールの設計
6. 校舎からの実施可否・定員回答の締め切り設定と回収フロー作成

### フェーズ3: 制作物作成
7. LP構成・コピーの確定(A・B施策それぞれ)
8. HPバナー等の作成依頼
9. りんご塾チラシの増刷手配(新規制作は不要、既存チラシ流用)
10. 広告クリエイティブ作成(オンライン/オフライン)

### フェーズ4: 実施・運用
11. 校舎からの回答をもとにHP掲載校舎を反映
12. 実施校舎への広告出稿
13. りんご塾イベントの講師アサイン(津村さん・本間さん・菅原さん等)・日程確定
14. 集計方法・トラッキングシートの作成(校舎別の反響記録)

### フェーズ5: 評価・ナレッジ化
15. 11月上旬に反響確認→11月まで延長するか判断
16. 実施後、「どの校舎が積極的に取りに来たか」「どのオファーの反応が良かったか」を記録
17. 来期(来年度以降)の型として設計に反映するレポート作成

## ④ このClaude上でできること/できないこと

### できること(準備・情報収集として着手済み)
| タスク | 状況 |
|---|---|
| 校舎向け案内文(選択式アナウンス)のドラフト作成 | `docs/school_announcement_draft.md` に作成済み |
| LP構成案・コピーのドラフト作成 | `docs/lp_draft.md` に作成済み |
| 競合(中学受験系個別指導塾)の秋キャンペーン事例リサーチ | 下記「競合リサーチ結果」参照 |
| 集計・トラッキングシートの項目設計(スプレッドシートの構成案) | 依頼があれば追加作成可能 |
| 逸失収益試算のロジック設計・計算補助(校舎別月謝データを共有いただければ算出可能) | データ提供待ち |
| 議事録・Slackログの要約・整理 | 本ドキュメント |

### できないこと(社内システム・権限・人が必要)
| タスク | できない理由 |
|---|---|
| 部長会議での承認取得 | 意思決定は人間(部長・事業部)が行う事項 |
| 実際のHP・LPへの反映(CMS更新) | testeaのウェブサイト管理システムへのアクセス権がない |
| 校舎への正式な一斉アナウンス配信 | Slack送信は技術的に可能だが、承認前の内容を堀内さんの代わりに送るべきではない。文面ドラフトの提供までに留める |
| 広告媒体への出稿・入稿 | 広告管理システム(Meta広告等)へのアクセス権がない |
| 校舎ごとの定員・実施可否の実データ回収 | 各校舎からの回答収集は人が対応する業務 |
| りんご塾講師(津村さん等)のシフト調整 | 人事・シフト管理の実務 |

### 競合リサーチ結果(参考情報)
低学年向け無料化・入会金免除は業界内でも一般的な打ち手であることを確認。テスティーの設計(入会金2.2万円のみ・授業料3ヶ月免除)は競合と比較して十分に競争力がある。
- 創研学院: 小学3年生の中学受験コースを**1年間授業料無料**(小3の基礎固め目的)
- そら塾: 入会金全額免除+最大1ヶ月無料体験
- 個別教室のトライ: 入会金無料+2ヶ月分授業料最大30%OFF
- 進学塾3Arrows: 9月に「小3ジュニア授業体験キャンペーン」を実施(時期も一致)

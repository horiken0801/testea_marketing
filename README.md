## ① 内容のまとめ

### 背景・目的
- 大手進学塾(サピックス等)の入室テストは小4開始が主流。小6での新規入会率は2〜3%程度と低く、**低学年(小3・4・5)での早期接点確保**が中長期的な在籍継続に直結するという中村さんの指摘が起点。
- 中村さん(9/29):「17期に向けて非常に重要な取り組み。低学年の子を何人抱えられるかが極めて大事」「秋キャンは低学年を集めた教室が勝ち」
- 単年の件数目標よりも**「毎年同時期に再現できる型」を作ることを重視**(松尾さんの視点、8/27時点)。ただし9/29時点では「議論より実行」を優先する方向に振れている(中村さん:「新年度同様に企画し直すというのはもう9月終わるんで、とにかくAをやろう」)。

### ★最新決定内容(9/29mtg時点・現時点の正)
**A. 中学受験準備応援キャンペーン(最優先・即実施)**
| 項目 | 内容 |
|---|---|
| 対象 | 小学3・4・5年生(**6年生は対象外**) |
| 内容 | 週1コースを**2ヶ月間・最大4コマ無料**で提供(振替なし、欠席したら消化) |
| 条件 | 入会金は必須(唯一の必須条件)。金額は9/10提案書の**2.2万円を継続使用(未変更の前提)** |
| 実施期間 | **10月1日〜2ヶ月間** |
| 告知方法 | 校舎への選択制ではなく、**本部決定事項として各校舎へ通知**するのみ(中村さん:「本部で決めたって言ってこれ通知してくれれば大丈夫」) |
| 想定費用試算 | 工数がかかるなら**実施しなくてよい**と明言されている(中村さん) |

**B. りんご塾 体験イベント → 1ヶ月ペンディング**
- Aの運用開始から1ヶ月後に、冬期用/新年度用どちらで実施するか改めて議論
- 現時点では並行実施しない(堀内さんのリソースをAに集中させる判断)

> 9/10提案書にあった「3ヶ月間授業料完全免除・校舎選択制」という設計は、9/29mtgで「とにかく最短でAだけやる」という方針に上書きされている。9/10提案書は参考資料として残すが、**実行のベースは9/29の決定を優先する**。

## ② やることのスモールタスク化(9/29決定反映版)

### フェーズ1: LP作成(最優先・Claudeで対応可能)
1. 既存の夏キャンLP(またはセンター南新設ページ)を素材として、秋キャン(A)の内容に書き換え
2. コピー・構成の確定(中村さん・半田さんの意向:過去のLPを流用し、AIに音声入力/画像を与えて書き換えさせるのが速い)
3. HPへの反映依頼(反映自体はClaudeでは不可、Web担当への引き渡しが必要)

### フェーズ2: 校舎への通知
4. 「本部決定事項」としての通知文言を作成(選択制ではなく実施告知のトーン)
5. マーケティング部全体チャンネル→事業部→各校舎への配信フロー確認
6. 無料コマ発生に対する現場からの懸念に備えたFAQ・Q&Aの用意

### フェーズ3: 告知・実施
7. ホームページでの告知(10/1公開目標)
8. 告知ブログの作成(センター南開校ブログと合わせて、または秋キャン単独で)
9. 実施開始後、問い合わせ数を日次でトラッキング(既存の計測フローに合わせる:メール・新規状況2.0・ポータル系)

### フェーズ4: B(りんご塾)の再検討(1ヶ月後)
10. 11月頭を目安に、Aの実施状況を踏まえてBを冬期用/新年度用どちらで実施するか判断する

### フェーズ5(継続・並行タスク): 未決・元在生アプローチ / ステップメール精査
11. 未決・元在生向けメール文面の配信(半田さん確認待ち→本日中配信予定だった)
12. AIが指摘したステップメール(50本中40本要修正)の内容精査・差し替え

### 競合リサーチ結果(参考情報)
低学年向け無料化・入会金のみでの入会は業界内でも一般的な打ち手であることを確認済み。
- 創研学院: 小学3年生の中学受験コースを**1年間授業料無料**
- そら塾: 入会金全額免除+最大1ヶ月無料体験
- 個別教室のトライ: 入会金無料+2ヶ月分授業料最大30%OFF
- 進学塾3Arrows: 9月に「小3ジュニア授業体験キャンペーン」を実施(時期も一致)

テスティーの「2ヶ月間・最大4コマ無料+入会金のみ」は競合と比較して十分競争力がある設計。

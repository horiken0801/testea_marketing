# 参考データ置き場（Threads / X 共通）

このフォルダに `.md` または `.txt` ファイルを置くと、下書き生成時（`scripts/draft_threads_posts.py` / `scripts/draft_x_posts.py` 共通）に追加の参考情報としてAIに渡されます。

現状の中身はほぼThreadsでの実績データですが、X向け生成でも「保護者がどんな言葉に反応しやすいか」という参考情報として使われます。ただし文面はThreadsの投稿を流用せず、X向けに毎回新規作成する設計です（プロンプト側でその旨を明示しています）。

**X専用のデータ（X運用の指示書、X自身の投稿実績など）は、このフォルダではなく `data/reference_x/` に置いてください。** そちらはX生成でのみ読み込まれ、Threads側には渡りません。

例:
- 過去の投稿一覧とその反応（いいね数・保存数など）のメモ
- 自社サイト・ブログの最新記事リスト
- 注目している塾・学校・競合アカウントの情報
- 直近伝えたい訴求ポイントやキャンペーン情報

このREADME.mdファイル自体は読み込み対象から除外されます。ファイル名・拡張子は自由ですが、`.md` または `.txt` のみが読み込まれます。

## ファイル一覧

- `00_recent_results.md`: **直近実績サマリ（軽量・週次追記用）**。毎週、投稿ごとの閲覧数・インタラクション・本文をここに追記していく想定。新しい成果を共有したいときはまずこのファイルを更新してください（スクリーンショットを共有いただければ代わりに書き起こします）
- `04_raw_post_history.md`: 過去1か月強の投稿・判断・反応の詳細ログ（生データ寄り）
- `05_dm_case_log.md`: DM相談のケースログ（返信方針・文体調整のポイント）
- `06_instagram_account_data.md`: Instagram本体（@handa_chugakujuken）の投稿実績データ。Threads投稿のInstagram流入率の要因分析（対比構造仮説）の検証に使用
- `投稿作成用詳細ファイル.md`: 投稿下書き作成時の運用ルール・強かった/弱かったテーマ
- `DM返信作成用詳細ファイル.md`: DM返信文を作るときの参考メモ
- `学校相談・附属校相談用詳細.md`: 学校相談・附属校相談時の参考情報

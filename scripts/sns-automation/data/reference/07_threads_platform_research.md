## 2026-10-01 調査: Threadsアルゴリズムの評価基準・成長施策

### アルゴリズムの評価基準（2026年時点）
- **「返信数」が最重要指標**。いいね数より、投稿にどれだけ質の高い返信・議論が生まれたかがおすすめ枠掲載を左右する。Xの調査結果(返信がいいねの約8倍重視)と同じ傾向
- **投稿後30〜45分の初速**が、その後のレコメンド(おすすめ表示)への乗りやすさを決める
- **投稿の鮮度が重要**で、新しい投稿ほどおすすめに表示されやすい
- **投稿頻度は1日1〜3投稿、最低でも週3回以上が理想**。現状の運用(週7投稿＝ほぼ毎日1投稿)はこの基準を満たしている
- **リプライへの投稿者自身の返答がエンゲージメントを高める**。会話のキャッチボール(ラリー)が続くほど評価が上がる
- **トピックタグは1つに絞るのが正解**（複数設定は逆効果）。現状「中学受験」タグを1つ使う運用は既に適切
- **画像やカルーセルを添付した投稿の方がエンゲージメント率が高まる傾向**。現状は全投稿がテキストのみのため、試験的に画像添付を検討する余地がある

### Instagram連携の仕組み
- ThreadsはInstagramと連携しており、Instagram側の「親密度」判定（普段のDMのやり取りやストーリーズへの反応など）がThreadsのおすすめ表示にもそのまま反映される仕組みがある
- コメント欄が活発に動くと、アルゴリズムが「エンゲージメントが高く人を惹きつけている」と判断し、フォロワー以外への「おすすめ」枠に一気に拡散される

### 実務への反映
1. **投稿後30〜45分の初期反応が重要**なため、投稿直後についたリプライには運用者が早めに返信することを引き続き推奨（Xと共通の申し送り事項）
2. **トピックタグ「中学受験」1つのみの運用は現状のままで問題ない**
3. **画像添付は今後試験投入を検討**（今回のバッチでは見送り、次回以降の実験候補として記録）
4. 現状の投稿頻度（週7投稿）は基準を満たしているため、頻度面の変更は不要

## 2026-10-01 調査: 中学受験カレンダー(10月)

- 10月は多くの6年生が**過去問演習を本格化させる時期**。まとまった時間が取れる日に4教科通しを月1〜2回、平日に2教科を週1回のペースが目安とされる
- **10月〜12月は第一志望校・併願校の最終決定、学校説明会が集中する追い込み期間**。志望校選びのテーマは今の時期特に検索・相談されやすい

## 2026-10-15 調査: リンク付き投稿の伸び悩みと「見つかりやすさ」の仕組み（秋期キャンペーン投稿のテコ入れ用）

**背景**: 10/10投稿の秋期キャンペーン(URL誘導形式)が週内最低の結果(閲覧133・プロフィールアクセス0)だったため、原因と改善策を調査した。

### リンク付き投稿がリーチしにくい傾向（公式発表はないが複数の運用者が報告）
- Threadsは**ユーザーをアプリ外に出す投稿の表示を抑える傾向がある**という説が運用者の間で広く共有されている(Meta公式のペナルティ発表はなく、「シャドウバン」の明確な定義も公表されていない)
- 実務上の回避策として紹介されている方法:
  1. **本文にはURLを置かず、まずThreads内で完結する読み応えのある文章を書く**
  2. **リンクは投稿本体ではなく、自分自身の返信(セルフリプライ)に入れる**
  3. 固定ポストにリンクをまとめ、本文側では直接URLを書かない

### 「広告っぽさ」を弱める書き方
- バナー調の画像、「今すぐ」等の煽り文、ハッシュタグの乱用は広告臭の原因になりやすい
- 「買ってください」ではなく「この課題に心当たりはありませんか」のように、**売り込みではなく問いかけの形**にすると受け入れられやすい
- 告知投稿だけを連投せず、通常の気づき・相談ベースの投稿と混在させる

### 2026年時点のアルゴリズム新要素
- **会話が活発な投稿がアルゴリズムの重要シグナル**として扱われる(従来の「返信数重視」と同じ方向性を補強)
- 添付テキスト機能(本文500字upper限に加え、最大1万字まで拡張可能)が追加されているが、キャンペーン訴求には必須ではない

### 実務への反映（秋期キャンペーン投稿の改善方針）
1. **本文にURLを直接書かない**。これまで通り「症状提示→『秋キャンペーン』とDMください」という、既にフォロワーが慣れている導線に戻し、詳細・リンクはDM側で個別に案内する
2. 内容は「早期対策」という抽象的な訴求ではなく、**他の症状特化型投稿と同じレベルの具体性**(6年生からの詰め込みで実際に困った事例など)に寄せ、通常投稿との質感の差をなくす
3. バナー画像は使わず、引き続き生写真または画像なしで投稿する
4. どうしてもURLを本文に残したい場合は、本文を先に完結させた上でセルフリプライにURLを入れる形式を試す(本体の文章はDM誘導と同じトーンに保つ)

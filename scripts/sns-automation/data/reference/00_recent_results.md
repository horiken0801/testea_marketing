# Threads 直近実績サマリ（軽量更新用・週次追記）

## このファイルの目的
`04_raw_post_history.md` などの詳細ログとは別に、直近の投稿実績だけを短く・追記しやすい形でまとめるためのファイルです。
下書き生成時、AIはまずこのファイルの最新セクションを優先的に参照します。

## 更新方法（週次目安）
1. Threadsアプリの「インサイト」→対象の投稿を開く
2. 本文・閲覧数・閲覧内訳・インタラクション（いいね/返信/引用/再投稿）・プロフィール遷移によるフォロー数を確認
3. このファイルの一番上（このすぐ下）に新しいセクションとして追記する（過去のセクションは消さずに残す）
4. スクリーンショットをチャットに貼っていただければ、代わりに書き起こして追記します

### 「いいねが少ない」への回答（繁田先生への説明材料）
- 今回のバッチでは、**いいね率が0%の投稿でも、プロフィールアクセス・フォロー・返信という「次の行動」に繋がる指標は複数投稿で発生している**（附属校: プロフィールアクセス331件・返信率0.04%／模試相談: プロフィールアクセス25件・返信率1.16%／苦手科目: プロフィールアクセス22件・フォロー1件）
- 中学受験という個人的なテーマの性質上、保護者は「いいね」で公にリアクションするより、**静かに読んでプロフィールやDMに移動する**行動を取りやすいと考えられる。いいね数は「見た人のうち、その場で反応を残した人」の指標に過ぎず、「実際に一歩踏み込んだ人」を測るには不向き
- 結論として、**いいね数の少なさは問題ではなく、プロフィールアクセス・フォロー・返信率という行動指標を重視する現在の方針は妥当**と判断できる

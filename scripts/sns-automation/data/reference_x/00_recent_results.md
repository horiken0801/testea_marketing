## 仮説メモ: 拡散が起きない原因について（2026-08-14時点、ディレクター確認事項）

**背景**: 3か月間(5/8〜8/5)で有効投稿はわずか20本（4〜5日に1本ペース）。直近週(8/8〜8/14)も計画5本/週に対し実施2本と、運用に断続的な空白期間がある。ディレクターから「運用していない期間があった。それが拡散されない原因か」という確認があり、以下の仮説を返した。

**仮説（2つの要因が併存している可能性が高い）**:
1. **投稿頻度の不安定さ**: 空白期間があるとフォロワーへの到達習慣が作られず、「フォロワーに定期的に届く」信頼が弱くなる。
2. **リプライ・リポストの絶対的な少なさ（より根本的な要因の可能性）**: 3週間・20投稿の累積で「いいね1件、エンゲージメント合計10件」のみ。閲覧が伸びた投稿(8/4 imp42など)でもリプライ・リポストはほぼゼロ。Xのアルゴリズムは投稿直後のリプライ・リポストを強く見てフォロワー外への配信（拡散）を判断するため、**投稿を安定させるだけでは「フォロワー外に届くスイッチ」は入らない可能性がある**。

**優先順位の提案**:
1. まず投稿を計画通り安定させる（空白を埋める）
2. リプライを狙う投稿（議論・テーマ提起、相談・DM化の問いかけ）を、より具体的で答えやすい形に強化してテストする

**今後の下書き生成への反映**: 議論・テーマ提起／相談・DM化カテゴリでは、末尾の問いかけを「はい/いいえで終わらない、具体的に答えたくなる質問」にする方向を優先的に試すこと。
